## Installation
Dusk Zsh Theme **only** works with _[Oh-my-zsh](https://ohmyz.sh/)_. Installation is simple and straight forward.
```sh
# Clone repository
git clone https://github.com/Teja2106/dusk.zsh-theme

# make sure to cd into the directory if you're not cloning into '.'

# Move the .zsh-theme file to Oh-my-zsh custom theme folder
mv dusk.zsh-theme $ZSH/custom/themes

# Set theme in your .zshrc
ZSH_THEME="dusk"
```
